# Lab2 — Interface Web

Deuxième exercice du cours « Développement d'interfaces Web ». Le projet est un site statique réalisé en HTML et CSS.

## Objectifs de l'exercice

- Ajouter à la page précédente un en-tête, un logo, un titre, un menu de navigation, un tableau et un pied de page.
- Créer un tableau d'au moins quatre colonnes et six lignes, avec des cellules fusionnées et des couleurs différentes pour les lignes paires et impaires.
- Faire occuper toute la largeur de la fenêtre à l'en-tête et au pied de page.
- Centrer le contenu et le menu, avec une largeur maximale de 960 px.
- Séparer les styles du contenu en plaçant le CSS dans un fichier distinct.
- Utiliser les éléments sémantiques `header`, `nav` et `footer`.

## Contenu du site

- Un en-tête avec un logo et un menu qui mène aux différentes sections.
- Une liste de liens illustrant plusieurs types de liens HTML.
- Un tableau de résultats étudiants : disciplines, notes, coefficients, résultats et moyenne pondérée. Il comporte quatre colonnes, six lignes de données, dont une ligne de moyenne avec des cellules fusionnées, et des couleurs alternées.
- Un formulaire avec validation des champs, choix du sexe et saisie du langage de programmation préféré. Des suggestions sont proposées, mais un autre langage peut aussi être saisi.
- Un pied de page.

## Fichiers

| Fichier | Rôle |
| --- | --- |
| `index.html` | Structure et contenu de la page |
| `style.css` | Mise en forme et adaptations aux écrans étroits |
| `image.png` | Logo affiché dans l'en-tête |
| `image.jpg` | Image liée depuis la liste de liens |

## Ouvrir le site

Aucune installation ni compilation n'est nécessaire. Ouvrir `index.html` dans un navigateur. Pour publier le projet, héberger les fichiers du dossier sur un service de pages statiques, par exemple GitLab Pages.

> Le formulaire est uniquement une interface HTML : aucun serveur n'est configuré pour traiter ou enregistrer les données envoyées.
